۴ · فطرت

فطرت و ابعاد آن

وجودی ← معرفتی ← گرایشی

بُعد وجودی

نوعی آفرینش + تجهیزات لازم برای رسیدن به غایت

بُعد معرفتی

شعور باطنی + دریافت بدون استدلال

بُعد گرایشی

آزادی، عشق، زیبایی، حقیقت‌جویی، عدالت

ویژگی‌های فطرت

تبدیل‌ناپذیری + هدایتگری + تکوینی + تضمین سعادت

غریزه و فطرت

غریزه ← مشترک انسان و حیوان
فطرت ← مختص انسان + متعالی
دام: غریزه = مشترک / فطرت = مختص

فطرت و شاکله

فطرت ← تبدیل‌ناپذیر ← عین ذات
شاکله ← تغییرپذیر ← ساخته انسان
نکات فطرت:
  • آیه مهم فطرت: روم/۳۰
  • هدایت عام: حرکت تکوینی همه موجودات به سوی غایت
  • ترس: یادآور اعتقاد فطری (نه پدیدآورنده)
  • برهان فطرت با محبت: انعام/۷۵-۷۹
  • حکم فطرت = حکم عقل
  • ابن‌سینا: فطرت اولی صحیح = عقل
  • علامه طباطبائی: ادراک حق و باطل در سرشت انسان
  • شهید مطهری: فطرت = امور ماورای حیوانی و مقدس

۱۶ · مراحل تربیت نفس

مشارطه

انسان با خدای خود عهد و پیمان می‌بندد که گناه نکند

مراقبه

از هنگام بیداری تا خواب مواظب و مراقب خود باشد

محاسبه

در پایان روز، درباره همه اعمال و اندیشه‌ها مرور و تفکر کند

معاتبه

خود را سرزنش کرده و مورد عتاب و عقاب قرار داده و توبه کند
دام: ترتیب مراحل = مشارطه ← مراقبه ← محاسبه ← معاتبه

۲۶ · اگر فقط ۵ دقیقه وقت داشتی!

  1. وجه جامع آسیب‌ها = معنوی
  2. دوره ایمان بر عقل = قرون وسطی
  3. راه فطرت = بدون استدلال / شهودی
  4. اولین دلیل اختیار = وجدان
  5. جبر = نفی فعل از انسان + انتساب به خدا
  6. امر بین الامرین = استناد به انسان و خدا در طول هم
  7. قضا = حتمیت / قدر = اندازه
  8. ۳ بُعد فطرت = وجودی + معرفتی + گرایشی
  9. فطرت = تبدیل‌ناپذیر / شاکله = تغییرپذیر
  10. ۳ دلیل امکان معاد = آفرینش دوباره + قدرت بی‌نهایت + تفکر در طبیعت
  11. ۴ دلیل ضرورت معاد = وعد و وعید + حکمت + عدالت + میل به جاودانگی
  12. نسخ = انسان / مسخ = حیوان / فسخ = گیاه / رسخ = جامد
  13. ملاک خلود = رسوخ ملکات در نفس
  14. بزرگ‌ترین نعمت مورد سوال = هدایت و ولایت
  15. علت اصلی ورود به بهشت = بندگی
